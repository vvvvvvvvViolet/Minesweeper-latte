# Minesweeper Latte

เกม Minesweeper เล่นบนเว็บ ธีมโทนกาแฟนม — **บันทึกเกมได้** และ **ย้อนกลับได้**

เขียนด้วย HTML / CSS / JavaScript ล้วน ไม่มี dependency และไม่ต้อง build
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ก็เล่นได้ทันที

---

## เล่นออนไลน์

Deploy ขึ้น **GitHub Pages** อัตโนมัติทุกครั้งที่มีการ push เข้า `main`
ผ่าน `.github/workflows/deploy.yml` (จะรันเทสต์ก่อน ถ้าไม่ผ่านจะไม่ deploy)

URL: `https://vvvvvvvvviolet.github.io/Minesweeper-latte/`

ครั้งแรกที่ workflow รัน มันจะเปิดใช้งาน Pages ให้เอง (`enablement: true`)
ถ้าองค์กรตั้งค่าไม่ให้เปิดอัตโนมัติ ให้ไปที่ **Settings → Pages** แล้วเลือก
**Source: GitHub Actions** ครั้งเดียว จากนั้นสั่ง re-run ได้เลย

## เริ่มเล่น (บนเครื่องตัวเอง)

เปิดไฟล์ตรง ๆ:

```
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

หรือเสิร์ฟผ่าน static server ตัวไหนก็ได้:

```
python3 -m http.server 8000    # แล้วเปิด http://localhost:8000
```

## ฟีเจอร์หลักตามที่ขอ

### 💾 บันทึก (Save)

- กดปุ่ม **บันทึก** (หรือ `Ctrl` + `S`) เพื่อเก็บเกมปัจจุบันลง **3 ช่องบันทึก**
- แต่ละช่องแสดงระดับความยาก ขนาดกระดาน สถานะ เวลาที่ใช้ และเวลาที่บันทึก
- กดปุ่ม **โหลด** เพื่อเรียกเกมกลับมาเล่นต่อ — กระดาน ธง เวลา และประวัติการย้อนกลับ
  กลับมาครบเหมือนตอนที่บันทึกไว้ ลบช่องที่ไม่ใช้แล้วได้จากหน้าต่างเดียวกัน
- **บันทึกอัตโนมัติ**: ทุกครั้งที่เดิน เกมจะถูกเก็บไว้เงียบ ๆ ถ้าปิดแท็บหรือรีเฟรช
  แล้วกลับเข้ามาใหม่ จะเล่นต่อจากจุดเดิมได้เลย
- ข้อมูลทั้งหมดเก็บใน `localStorage` ของเครื่องผู้เล่น ไม่มีการส่งออกไปที่ไหน
  ถ้าเบราว์เซอร์ปิดการเก็บข้อมูลไว้ เกมจะยังเล่นได้ (เก็บไว้ในหน่วยความจำชั่วคราว)
  และจะมีข้อความแจ้งเตือนในหน้าต่างบันทึก

### ↩︎ ย้อนกลับ (Back / Undo)

- กดปุ่ม **ย้อนกลับ** (หรือ `Ctrl` + `Z`) เพื่อถอยกลับทีละตา ได้ลึกสุด **40 ตา**
- ย้อนได้ทุกการกระทำ ทั้งเปิดช่อง ปักธง และการเปิดรอบ ๆ ตัวเลข
- **ย้อนตาที่เหยียบระเบิดได้ด้วย** — เกมที่แพ้แล้วจะกลับมาเล่นต่อได้
  พร้อมย้อนเวลาบนนาฬิกากลับไปที่ตานั้นเหมือนกัน
- ตัวเลขข้างปุ่มบอกว่าเหลือย้อนได้อีกกี่ตา
- เพื่อความยุติธรรม เกมที่ใช้ปุ่มย้อนกลับจะไม่ถูกบันทึกเป็นสถิติเวลา

## ระดับความยาก 5 ระดับ

ไล่ระดับขึ้นทั้งขนาดกระดานและความหนาแน่นของระเบิด

| ระดับ | กระดาน | ระเบิด | ความหนาแน่น |
| --- | --- | --- | --- |
| มือใหม่ | 7×7 | 5 | 10.2% |
| ง่าย | 9×9 | 10 | 12.3% |
| ปานกลาง | 16×16 | 40 | 15.6% |
| ยาก | 16×30 | 99 | 20.6% |
| โหด | 20×40 | 180 | 22.5% |

บวกกับโหมด **กำหนดเอง** ที่ตั้งขนาดกระดานและจำนวนระเบิดได้เอง
(5–30 แถว, 5–40 คอลัมน์) และมีการเก็บสถิติเวลาที่ดีที่สุดแยกของแต่ละระดับ

รายการระดับความยากอยู่ที่ `DIFFICULTIES` และ `PRESET_ORDER` ใน `js/game.js`
ที่เดียว — เมนูเลือกระดับและแถบสถิติสร้างจากตรงนั้น ถ้าจะเพิ่มระดับใหม่
แก้ที่นั่นที่เดียวพอ ไม่ต้องแตะ HTML

## ออกแบบมาเพื่อมือถือ

หน้าเว็บเขียนแบบ mobile-first แล้วค่อยขยายขึ้นเป็นจอใหญ่

**การควบคุมด้วยนิ้ว**

- **สลับโหมดแตะ** ⛏️ เปิด / 🚩 ปักธง — มือถือไม่มีคลิกขวา การสลับโหมดจึงเร็วกว่า
  การกดค้างมาก เวลาต้องปักธงติด ๆ กันหลายช่อง ช่องที่ยังไม่เปิดจะเปลี่ยนสี
  บอกให้รู้ว่ากำลังอยู่โหมดปักธง
- **กดค้าง = ทำสิ่งตรงข้ามกับโหมดปัจจุบันเสมอ** อยู่โหมดเปิดกดค้างคือปักธง
  อยู่โหมดปักธงกดค้างคือเปิด ไม่ต้องสลับโหมดไปมาเพื่อทำครั้งเดียว
- ปิด callout menu ของ iOS ตอนกดค้าง และมีสั่นตอบรับเมื่อปักธงสำเร็จ
- ลากนิ้วเพื่อเลื่อนกระดานได้โดยไม่ปักธงพลาด และไม่เผลอ pull-to-refresh
  หรือปัดย้อนกลับระหว่างเลื่อนกระดาน

**เลย์เอาต์**

- **แถบปุ่มติดขอบล่างจอ** อยู่ในระยะนิ้วโป้ง ทุกปุ่มสูงอย่างน้อย 44px
  ตามขนาดเป้าแตะขั้นต่ำ
- **แถบสถานะ (ระเบิดคงเหลือ / เวลา / หน้ายิ้ม) ปักหมุดไว้ด้านบน** เลื่อนดูกระดาน
  ใหญ่ ๆ ก็ยังเห็นตลอด
- **กระดานอยู่บนสุดของหน้า** ส่วนตั้งค่าและวิธีเล่นถูกย้ายลงล่าง (วิธีเล่นพับเก็บไว้)
- ขนาดช่องปรับตามหน้าจอ พอดีจอเมื่อพอดีได้ และไม่เล็กกว่า 26px เสมอ
  ถ้าไม่พอดีก็เลื่อนดูได้ทุกคอลัมน์
- **แนวนอนก็ใช้ได้จริง** ซ่อนหัวเรื่อง ย่อแถบสถานะ และคำนวณขนาดช่องจากความสูง
  ที่เหลือ เพื่อให้เห็นทั้งกระดานโดยไม่ต้องเลื่อน
- รองรับรอยบาก/ขอบโค้ง ด้วย `env(safe-area-inset-*)` และ `viewport-fit=cover`
- ไม่ปิด pinch zoom (ตาม WCAG 1.4.4) แต่กันดับเบิลแท็ปซูมบนกระดานไว้

**ติดตั้งลงเครื่องได้**

- มี **web app manifest** + ไอคอน (รวมแบบ maskable) กด "เพิ่มไปยังหน้าจอโฮม"
  แล้วเปิดเต็มจอเหมือนแอปจริง
- มี **service worker** แคชไฟล์ทั้งหมด → เปิดเร็วและ **เล่นตอนออฟไลน์ได้**
- `theme-color` แยกสำหรับโหมดสว่าง/มืด ให้แถบสถานะของระบบกลมกลืน

## ฟีเจอร์อื่น ๆ

| หมวด | รายละเอียด |
| --- | --- |
| ช่องแรกปลอดภัย | ระเบิดจะถูกวางหลังคลิกแรก โดยเว้นช่องที่กดและช่องรอบ ๆ ไว้เสมอ |
| การเปิดพร้อมกัน | แตะ/ดับเบิลคลิก/คลิกกลางบนตัวเลขที่ปักธงครบแล้ว เพื่อเปิดช่องรอบ ๆ ทีเดียว |
| คีย์บอร์ด | ลูกศรเลื่อนช่อง · `Enter`/`Space` เปิด · `F` ปักธง · `Ctrl+Z` ย้อน · `Ctrl+S` บันทึก |
| โหมดมืด | ปรับตามการตั้งค่าของระบบอัตโนมัติ |
| สถิติ | เก็บเวลาที่ดีที่สุดของแต่ละระดับความยากไว้ในเครื่อง |
| การเข้าถึง | มี ARIA label ทุกช่อง, `aria-pressed` บนปุ่มสลับโหมด และรองรับ `prefers-reduced-motion` |

## โครงสร้างโปรเจกต์

```
index.html              โครงหน้าเว็บ (เรียงลำดับแบบ mobile-first)
css/styles.css          ธีมกาแฟนม + โหมดมืด + เลย์เอาต์มือถือ/แนวนอน/เดสก์ท็อป
js/game.js              ตรรกะเกมล้วน ๆ (ไม่ยุ่งกับ DOM) — วางระเบิด, เปิดช่อง, แพ้/ชนะ, snapshot
js/storage.js           จัดการ localStorage — ช่องบันทึก, บันทึกอัตโนมัติ, สถิติเวลา
js/main.js              เชื่อม UI กับตรรกะเกม — เรนเดอร์กระดาน, โหมดแตะ, ประวัติย้อนกลับ, นาฬิกา
sw.js                   service worker สำหรับเล่นออฟไลน์
manifest.webmanifest    ข้อมูลแอปสำหรับติดตั้งลงหน้าจอโฮม
icons/                  ไอคอนแอป (SVG + PNG สำหรับ iOS)
tests/                  ชุดทดสอบ
.github/workflows/      CI และ deploy ขึ้น GitHub Pages
```

การแยก `game.js` ออกจาก DOM ทำให้ทั้งการย้อนกลับและการบันทึกใช้กลไกเดียวกันคือ
`snapshot()` / `restore()` — ปุ่มย้อนกลับคือการเก็บ snapshot ไว้ในหน่วยความจำ
ส่วนปุ่มบันทึกคือการเขียน snapshot ชุดเดียวกันลง `localStorage`

## การทดสอบ

ทดสอบตรรกะเกม (ไม่ต้องติดตั้งอะไรเพิ่ม):

```
node tests/engine.test.js
```

ทดสอบผ่านเบราว์เซอร์จริง (ต้องมี Playwright):

```
npm ci
npx playwright install chromium
node tests/ui.test.js
```

หรือรันทั้งสองชุดด้วย `npm test` — และทั้งสองชุดรันอัตโนมัติบนทุก pull request

ชุดทดสอบครอบคลุมช่องแรกปลอดภัย ความถูกต้องของตัวเลขข้างเคียง การแพ้/ชนะ
การย้อนกลับ (รวมถึงย้อนตาที่แพ้) การบันทึก/โหลด การเล่นต่อหลังรีเฟรช
ระดับความยากทั้ง 5 ระดับ การเล่นด้วยคีย์บอร์ด และฝั่งมือถือ ได้แก่
การแตะ/กดค้าง/สลับโหมด ขนาดเป้าแตะ แถบปุ่มล่างจอ เลย์เอาต์แนวนอน
manifest กับไอคอน และการโหลดเกมขึ้นมาเล่นตอนออฟไลน์จริง ๆ
